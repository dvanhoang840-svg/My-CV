## Điểm nhấn kỹ thuật

- **Chuẩn HTML5 ngữ nghĩa:** Sử dụng chuẩn `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<figcaption>`, `<footer>`.
- **CSS3 Mobile-First:** Tối ưu hóa từ màn hình điện thoại (360px), máy tính bảng (768px) đến máy tính để bàn (1024px, 1200px) mà không bị tràn cuộn ngang.
- **Họa tiết & Bảng màu sáng tạo:**
  - Kết hợp Xanh dương (`#2563eb`), Xanh tím (`#4f46e5` / `#7c3aed`), Cyan (`#06b6d4`), Xanh Navy (`#0b2545`) và các khối màu Pastel.
  - Các khối màu gradient mờ (Blobs) chuyển động bồng bềnh ở nền, lưới chấm nhỏ (Dot Matrix) và các ký hiệu công nghệ mờ (`</>`, `{ }`, `0101`, `✦`, `>_`).
- **JavaScript thuần (Vanilla JS):**
  - Menu di động đóng/mở mượt mà (Hamburger toggle).
  - Hoạt họa thanh tiến trình kỹ năng tự động kích hoạt khi cuộn tới phần Skills.
  - Hiệu ứng xuất hiện nhẹ (Scroll Reveal với `IntersectionObserver`) có độ trễ tự nhiên.
  - Nút quay lại đầu trang (Back to Top) tự động hiển thị và cuộn êm ru.
  - Tự động đánh dấu (active) mục menu theo vị trí đang xem.
  - Cửa sổ xem câu chuyện kỷ niệm hỗ trợ đóng bằng phím ESC và bấm ra ngoài.
- **Không phụ thuộc thư viện nặng:** Không dùng React, Next.js, jQuery, Bootstrap hay font-awesome cồng kềnh; tải nhanh tức thì trên mọi đường truyền.

## Hướng dẫn xem & Chạy thử trên máy

### Cách 1: Mở trực tiếp bằng trình duyệt
Nhấp đúp chuột vào tệp `index.html` hoặc kéo tệp vào trình duyệt bất kỳ (Microsoft Edge, Google Chrome, Firefox, Safari).

### Cách 2: Chạy qua máy chủ nội bộ Python
Nếu máy đã cài sẵn Python:

```powershell
# Chạy trên Windows PowerShell
python -m http.server 8080
```

Sau đó mở trình duyệt truy cập: `http://localhost:8080`
